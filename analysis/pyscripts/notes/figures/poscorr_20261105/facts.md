## Scripts and commands of the chain (output/r5ri_20261104/tools/chain_ri.sh, Commands.md:150-155)
Stages dump -> gains -> map -> maps -> final -> repro (`bash output/r5ri_20261104/tools/chain_ri.sh r5ri`, needs `ri_jobs.py --chain r5ri` first).
- ri_jobs.py: writes jobs/{dump,map,final,repro}.txt. run1_ri.sh/run1.sh: run one benchmark job (guards benchmark sha1).
- benchmark_hycal_timing_test_20261021.py (frozen): reconstruction + calibration + `--write-cluster-tsv`; `--pos-corr FILE` applies the map. Map-stage job (jobs/map.txt:1, no --pos-corr): `... prad_024386.evio.00010 output/r5ri_20261104/poscorr/scan/scan_024386/split_00010/result --calibrate --exclude-rowcol 15 20 15 20 --pre-window 100.0 200.0 --inner-radius 200 --min-per-module 30 --lms-corr off --hc-calib-file .../calibration_factor_3p5_June7_nonLinear.json --window 16.0 --time-calib off --pulse-method mf ... --gain-file output/r5ri_20261104/gains/024386/gains_024386_all.tsv --write-cluster-tsv --moller-reject kin --moller-kin-n 3 --moller-kin-m 2 --moller-reject-gains on --fit-select chi2 --cb-two-peak --cluster-profile geant4 --gain-refine off --nl-members on` (via output/merge_check_20261028/tools/merge_cfg_wrap.py --hycal-cfg output/r5_20261028/configs/reconstruction_config_r5.json). Final job (jobs/final.txt:1) is identical plus `--pos-corr output/r5ri_20261104/poscorr/maps/3p49GeV_H2/poscorr_r5ri_3p49GeV_H2_all.json`.
- percrystal_calib.py: per-crystal gains (stage gains), not part of the position correction itself.
- position_corr.py (maps stage): `map --scan-dir $S --out $M --splits all --workers 4`; per run type `fit --map $M/map_${s}_all.tsv --form bilinear --out $M/$s/poscorr_r5ri_bilinear_${s}_all.json`; for 3p49GeV_H2, 2p24GeV_H2, 2p24GeV_C `fit --per-module --scan-dir $S --splits all --slug $s --fallback $M/$s/poscorr_r5ri_bilinear_${s}_all.json --out $M/$s/poscorr_r5ri_${s}_all.json` (S=output/r5ri_20261104/poscorr/scan, M=.../poscorr/maps). Gate: norm within 0.02 of 1 and >=90% bins populated.
- plot_module_resolution.py: loaders/geometry used by position_corr.py (R.load_run, load_geometry). gate_scan_20261022.py: run-type slugs, R_PREF, git_info. compare_scan_dirs.py: per-split paired sigma comparison (form study). plot_cluster_energy_vs_position.py: earlier exploratory plot (not used here).
- Form study: output/poscorr_form_20261105/tools/heldout.py, sigma_table.py (README.md there). `fit --per-module --form {poly8,even6,even4}` was added to position_corr.py in that study (position_corr.py currently shows as modified in git).
