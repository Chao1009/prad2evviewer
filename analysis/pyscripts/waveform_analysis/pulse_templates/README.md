# pulse_templates: per-module PbWO4 cubic B-spline pulse templates

`waveform_analysis/template_extract.py` measures one unit-peak pulse shape per PbWO4 module and run type from clean single pulses in the data, as a penalised cubic B-spline, together with the pulse-to-pulse spread `shape_sigma(t)`. Every parameter is a constant at the top of the script; there are no flags.

The script is standalone: it needs numpy, scipy, matplotlib, uproot / awkward and the compiled `prad2py` binding (`source setup_env.sh` puts it on PYTHONPATH). It imports nothing else from the repository. The database directory is `$PRAD2_DATABASE_DIR`, or `<repo>/database` when that is unset.

```
python3 waveform_analysis/template_extract.py select <out.npz> <run type> <evio file> [<evio file> ...]
python3 waveform_analysis/template_extract.py build <run type>
```

"runinfo" means the file `database/runinfo/general.json` assigns to the run: the entry with the largest from_run <= run, inheriting the file of earlier entries. E_beam comes from the run's geometry. The runs are listed in `run_template_select.sh`; the 3p49GeV_H2 runs before 2026-11-10 were 24386, 24503 and 24512.

## select (one run: all its EVIO splits -> one npz)

1. Events: the trigger gate above. Events with the LMS bit (trigger_bits & 0x1000000) are dropped, and so are events with more than 20 PbWO4 channels at A >= 50 ADC.
2. Dead modules: the `hycal_dead_modules` entry of `general.json` with the largest from_run <= run (no chaining). Their channels are skipped entirely; the npz meta records the names and the matched from_run.
3. Channels: PbWO4 with 100 samples (4 ns). The WaveAnalyzer gives the pedestal and rms; w = samples - pedestal and A = max w. The cuts, on the raw samples and in this order (cut-flow names in brackets):
   - no sample >= 4095 (`c1_clip_ok`); A >= 50 ADC (`c5_amp_ge50`); peak sample <= 59 (`c4_contained`);
   - first sample above 2 ADC (before the peak) at sample >= 20, so a 20-sample pre-pulse window exists (`c3_first_thr`);
   - rms <= 1.5 ADC and |slope| of the pre-pulse window <= 0.05 ADC/sample (`c8_pedestal`);
   - tail back at baseline: |mean of samples peak+40 ... peak+50| <= max(2, 2 rms) + 0.04 A (`c9_tail`);
   - no secondary bump: no sample after the peak lies >= 0.10 A above the lowest sample between the peak and it (`c2_no_secondary`);
   - smooth (`c10_smooth`): w does not decrease over the contiguous run of samples above 2 ADC that ends at the peak, and none of the 8 samples after the peak exceeds its predecessor by more than 2 rms.
4. Onset: `t0_cfd` is where the rising edge first reaches 0.5 A, linear between the two samples (ns from the start of the readout).
5. Energy: `e_rough` = calibration factor x sum of w over samples floor(t0_cfd / 4 ns) - 3 ... 99 (MeV). It is rough: the sum runs to the end of the readout, unlike the WaveAnalyzer integral the calibration was made with. e_rough < 1.2 E_beam is required, which also drops channels without a calibration factor.
6. Stored: every pulse that passes, with raw samples (uint16), module (`midx`, `name`), `ped`, `rms`, `amp`, `peak_sample`, `t0_cfd`, `e_rough` (float32), `event_number`, `split` and `run`; plus the cut flow per module (`cutflow`, `cutflow_names`; `stored` counts after the e_rough cut) and the meta (cut constants, calibration file and sha1, dead modules and their source, E_beam).

## build (one run type, its select files `<RT>/pulses/run_<run>.npz`)

1. Pool: per module, the pulses with e_rough >= 0.5 E_beam (the seed crystal of an elastic cluster holds about 70 % of its energy). The next pulses below the threshold in e_rough (20 % of pool + held out) are held out for the smoothing choice. Pools are tried in this order and the first whose fit succeeds (no wiggle at lambda 1e4) is used: (1) the elastic pool if it has at least 20 pulses; (2) the general pool, the module's stored pulses with amplitude 200 ... 1000 ADC (above the noise floor, below the elastic amplitudes) if there are at least 20 of them (`pool_general` = 1): up to 1000 of them at random (fixed seed), 80 % of the band for the pool and the next pulses of the band, 20 % of pool + held out, as held-out pulses, with the spline and `shape_sigma` as for an elastic pool; (3) the elastic pool if it has 3 to 19 pulses; (4) the single pulse of largest amplitude (`single`, n_pool = 1); (5) the run-type average. A module without pulses gets the run-type average.
2. Alignment: pass 0 pools the pulses at their t0_cfd with A = amp. Each pass fits the spline (steps 3-4), puts t = 0 at its onset and refits every pulse's onset against it: (t0, A) by least squares over -20 ... 160 ns after the onset, with t0 searched within +-4 ns of the pulse's CFD onset on a 0.25 / 0.05 / 0.01 ns grid (the spline is tabulated every 0.05 ns). After 3 passes comes the final fit. `align_rms_ns` is the standard deviation over the pool of the final t0 - t0_cfd.
3. Points: every sample at tau >= -20 ns of every pool pulse, as y/A, with sigma^2 = (rms/A)^2 + (0.15 ns x slope)^2 + (0.012 x shape)^2 (shape and slope of the previous pass; zero in pass 0). Medians and MAD in 0.5 ns bins give the tail and `shape_err`.
4. Spline: cubic B-spline on -20 ... 416 ns. Knots every 0.5 ns (pool >= 100) or 1 ns up to 10 ns, then 1 ns to 20, 2 to 40, 4 to 80, 8 to 160 and 16 to 400 ns, plus knots at -10 and -1 ns; every spacing doubles if the solve fails. Beyond the last 0.5 ns bin with >= 5 points (T_data), pseudo-points every 4 ns follow an exponential fitted on [140 ns, T_data]. The weighted least-squares fit has the penalty lambda x integral f''^2. The result is scaled to unit peak, and t = 0 is put where it last rises through 0.5 % of the peak.
5. lambda: a pool of >= 10 pulses with held-out pulses is built with lambda = 1e2, 1e3 and 1e4, and the value whose final template gives the lowest mean chi2/dof on the held-out pulses wins; smaller pools use 1e3. If the shape then has spurious wiggles (an extremum of prominence >= 0.2 % of the peak at 2-150 ns, more than 3 ns from the peak), lambda goes up x10 (cap 1e4) and the module is rebuilt. Pools of >= 100 pulses skip this check: their data fix the shape at every sample phase, so an extremum there is a feature of the pulse.
6. Fallback 2: a module without pulses, with a failed fit or with wiggles at 1e4 gets the run-type average spline, built the same way (lambda = 1e4) from up to 20 pool pulses of every module with its own elastic (not general-pool) template. Dead modules (dead in every input run) keep their row with `valid` = 0, `dead` = 1 and the average.
7. `shape_err` is the statistical uncertainty of the 0.5 ns bin median of the pooled points, max(1.4826 MAD / sqrt(n), noise floor), in peak units, NaN beyond T_data. It says how well the data fix the mean shape.
8. `shape_sigma` is the pulse-to-pulse spread about the template, in peak units, measured for every module on its general band pool whichever pool the template came from: the pulses with 200 <= A <= 1000 ADC (at most 1000, random with the fixed seed) aligned to the module's final template (+-4 ns around their CFD onset, as in step 4), at least 50 aligned pulses required. The aligned pulses at their final onset and amplitude give the residuals R = y/A - f(t) for every sample from -8 ns to T_data. In each 2 ns bin of t, shape_sigma is the s >= 0 with median((R - median R)^2 / (s^2 + nv)) = 0.455, the median of a chi2 with one degree of freedom (the robust 1.4826·MAD estimator (sigma routine in template_extract.py)). The pedestal noise nv = v_ped (1 + 1/30) / A^2 is removed in quadrature: v_ped is the pool mean of the variance of each pulse's samples more than 20 ns before the onset, and 1/30 is the pedestal error. Bins with fewer than 8 points are dropped, and the bin values are interpolated linearly onto `t_grid`. `a_band` is the median fitted amplitude (ADC) of that band pool; shape_sigma is measured at a_band, the matched filter scales it by the square root of (a_band / max(A, 20 ADC)). Modules with fewer than 50 aligned band pulses (and dead modules) get the median shape_sigma and the median a_band of the modules that have one (`sigma_borrowed` = 1). `shape_sigma_elastic` is the same spread of the elastic fit pool itself, about its own template, for template pools that are elastic with >= 50 pulses (NaN otherwise); it is for the energy benchmark and as a reference, the matched filter reads `shape_sigma`. Jitter: for the same aligned band pulses, the 10-90 % rise time and the 90-10 % fall time of each pulse are measured on its baseline-subtracted raw samples (linear interpolation between samples, levels relative to the pulse's own peak sample), and `rise_jitter_ns` / `fall_jitter_ns` are their robust standard deviation (1.4826 x median absolute deviation) and `rise_med_ns` / `fall_med_ns` their median per module (NaN below 50 pulses). These are per-pulse quantities, not those of the template.

## Outputs (`pulse_templates/<RT>/`)

- `templates_<RT>.npz` (schema spline_templates_v3): one row per PbWO4 module. Keys: `names`, `module_id`, `valid`, `dead`, `fallback` (0 own template, 2 run-type average), `single`, `pool_general` (1: own template from the amplitude band pool), `sigma_borrowed`, `n_pool`, `lam_module`, `chi2_ndf`, `align_rms_ns`, `t_grid` (-8 ... 400 ns, 0.1 ns), `shape`, `shape_err`, `shape_sigma`, `a_band`, `shape_sigma_elastic`, `rise_jitter_ns`, `fall_jitter_ns`, `rise_med_ns`, `fall_med_ns`, the spline (`spline_k`, `spline_t`, `spline_c`, `spline_nt`, `spline_nc`), `avg_spline_t` / `avg_spline_c`, `T_end`, `onset_shift_ns` (final axis minus the t0_cfd axis), `t_pk`, `t50`, `iint_wa` (WaveAnalyzer integral of the unit template, mean over 256 onset phases), and `meta` (JSON: inputs, E_beam, constants, notes on shape_sigma, shape_sigma_elastic and the jitter). No f(A) table is produced.
- `templates_<RT>.pdf`: a summary page with rise and fall times, pool sizes, the array median and 90th percentile of shape_sigma(t) (solid) and of shape_sigma_elastic (dashed), the counts and the median rise / fall jitter; then the n_pool heat map; then 3 x 3 modules per page (dead modules left out). Each module panel shows the pooled points (3000 random), the spline with a +-shape_sigma band, and below it the binned residual with the same band; the title flags `single`, `general` and `sigma borrowed`. Last, example pages (2 x 5 panels): 10 random pool pulses from each of the 3 own-template modules nearest the beam hole (smallest |x| + |y|), and 30 random pool pulses from the outermost own-template modules (largest max(|x|, |y|) first, at most 20 per module); each panel shows samples - pedestal with the template at the pulse's fitted onset and amplitude, and the page title lists the modules and their pulse counts. Dead, single-pulse and general-pool modules are not used.
- `n_templates_map.png`: the n_pool heat map of the PbWO4 modules (x / y from `database/hycal_map.json`, +-350 mm). Run-type-average modules are hatched with x, general-pool modules with /, single-pulse modules outlined in red, dead modules white.
- `templates_<RT>.root` (written with uproot): the TTree `templates` with module, module_id, valid, fallback, single, pool_general, sigma_borrowed, a_band, n_pulses, lambda, chi2, rise_ns, fall_ns, rise_jitter_ns, fall_jitter_ns, rise_med_ns, fall_med_ns, t_pk, iint_wa, knots[], coeffs[], shape[4081], shape_err[4081], shape_sigma[4081] and shape_sigma_elastic[4081]; one TH1D `shape/<module>` per module (0.1 ns bins, errors = shape_sigma); and `meta`.

## Full extraction

`waveform_analysis/run_template_select.sh` runs `select` once per run (8 runs in parallel) for the runs of the four run types in the table (2p24GeV_C is not part of it), writing `<RT>/pulses/run_<run>.npz` and `<RT>/logs/run_<run>.log`. It then runs `build` for each run type (`<RT>/build.log`). It sources `setup_env.sh` itself and works from any directory. `DATA_DIR`, `NPROC` and the run lists are at its top; on the JLab ifarm `DATA_DIR` changes (and the paths in `setup_env.sh`), and a batch system submits one `select` job per run. `build` pools every `run_*.npz` in `<RT>/pulses/`, so that directory must hold only the current runs' files.

```bash
nohup waveform_analysis/run_template_select.sh > output/run_template_select.log 2>&1 &
```
