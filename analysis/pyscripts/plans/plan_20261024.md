## 1. Goal and approach

**Goal.** Replace the analytic two-τ pulse template, which is 1–2 % short of the raw sum on mid and large pulses and leaves χ²/dof of 100–730 above 500 ADC (note §6, §6.1), by a sampled per-module template per run type, built by a smoothing spline over phase-aligned clean pulses; then redo the pile-up benchmarks (per-module pile-up rate heat maps, pile-up examples, detection efficiency) and the energy-calibration harness with it, and record the results in the 20261023 note §9.

**Approach.** One Python pipeline in three deliverables, each ending at a user checkpoint before the next spends scan time:

1. **Templates (Deliverable 1).** A new tool reads EVIO with the `fit_pulse_template.py` machinery, selects clean single pulses with PASS 1's cuts plus the vetoes PASS 1 lacks (D2), pools ~50–200 pulses per module and run type, phase-aligns them, robust-averages in 0.5 ns bins, fits a weighted cubic B-spline with dense knots on the rise and sparse knots in the tail, iterates twice, and writes a ROOT file in PASS 2's layout plus an `.npz` and a per-module PDF. The port is cross-checked against the original macro on run 24386 (D1).
2. **Pile-up (Deliverable 2).** `mf_pulse.py` gains a sampled bank behind the same interface as the two-τ bank (h50 default byte-identical); `plot_pileup_examples.py` becomes a multi-run, per-module scan with a 50 MeV denominator and heat maps; the pile-up generator injects the sampled shape and a new matched-filter efficiency tool adds time matching and a fake rate to Table 4's "≥ 2 peaks" definition.
3. **Calibration (Deliverable 3).** The driver passes one template bank per run type; per-crystal gains are refitted on the new energies; the full scan is paired against `output/scan_20261023_pc/`, with a "pooled gains only" arm beside "pooled gains + seed-indexed" (D7 addition); the int-vs-rawsum and χ²/dof tables are redone; findings go to the note §9 (D8).

**Rejected alternatives (one line each).**
- Producing `_raw.root` for all 14 runs and running the macros as they are: the local `_raw.root` format is not what the macros read anyway (F1), and the Python stack reads EVIO (D1).
- One single best waveform per module (PASS 1's choice): noise of one 1–2 ADC-RMS waveform at 300–2500 ADC is 0.1–0.5 % of peak per sample, and "highest amplitude wins" picks clipped pulses; superseded by D2.
- Interpolating spline through sample points (PASS 1's `TSpline3`): reproduces noise; the smoothing spline over pooled phase-aligned points is the point of D2.
- A per-module free shape inside the matched filter (free τ): χ²/dof falls only 15–20 % and the form, not τ, limits large pulses (note §6).
- Extending the C++ `PulseTemplate`/`WaveAnalyzer.deconvolve` to sampled grids: out of scope (D6); the Python mf path carries the efficiency test.
- Evaluating `scipy` splines per module inside the matched filter: the filter is batched over channels; a fine lookup table per module keeps it batched (§5.2).

Per module and run type: pool ~50 good pulses, phase-align (fit t0 and A per pulse; samples as (t − t0, y/A)), pool the points, robust-average in fine time bins, fit a smoothing spline (knots dense on rise/peak, sparse in tail; zero before onset and at the end), unit peak, I_int by the WaveAnalyzer walk-out rule, per-bin uncertainty stored; two iterations (refit t0/A against the new template, drop the worst ~20 % by χ², re-pool). Keep PASS 1's quality cuts where applicable (≥ 4 rising / ≥ 10 falling samples, no secondary > 15 % outside ±6 samples, clean 20-sample pre-pulse tier); ADD a clipping veto, an amplitude band (300–2500 ADC, relaxed when a module lacks statistics), exactly one mf pulse in the readout at a low secondary threshold, nothing before 60 ns, pulse fully contained, pedestal RMS/slope cuts, tail back to baseline. Do NOT select on χ² to the two-τ template. Also build the template in two amplitude bands (100–400 and 400–2500) per run type as an amplitude-dependence check.

### 5.2 Design choices

- **Lookup table, not spline evaluation in the filter.** The filter evaluates the shape for thousands of (module, time) pairs per block; a 0.05 ns table (1152 × 3200 float32 ≈ 15 MB each for value and slope) keeps the Gauss–Newton and joint-fit steps batched. The table is built once per bank from the stored spline coefficients.
- **Missing modules.** A PbWO4 module without a row in the `.npz` (or marked `valid = 0`) takes the file's `shape_avg` and is listed in `fallback`; lead glass and Veto rows are skipped exactly as today (their calibration factors are 0).
- **Kernel length.** L = 24 (96 ns) stays for both banks; the sampled shape's support to 160 ns matters for I_int and for subtraction only, as the two-τ tail does today.

### 6.1 `select`: the EVIO pass (one process per split)

| # | Cut | Definition | Origin |
|---|---|---|---|

| 2 | exactly one mf pulse | the low-threshold mf finds exactly one pulse in the whole readout | new |

### 6.2 `build`: alignment, pooling, spline, iteration

`build --pulses "output/templates_spline/<slug>/pulses/*.npz" --run-type <slug> --h50 output/pulse_templates_h50.dat --out output/templates_spline/<slug>/templates_<slug> [--n-min 50 --n-min-relaxed 20 --n-max 200 --seed 1]`

Per module (PbWO4 rows from `p.hycal`, 1152):

1. **Pool and band (D4 chain).** Tier-2 candidates in `b0` across all splits of the run type. N ≥ 50 → `fallback = 0`. Else add the relaxed band [100, 2500] and tier-1 candidates → if N ≥ 20, `fallback = 1`. Else `fallback = 2`: the module gets the run-type average (step 8). If N > 200, a seeded random subsample of 200 (uniform over the pool, so the amplitude mix is not biased).
2. **Iteration 0 alignment.** Per pulse, fit (A, t0) against the module's h50 two-τ shape (aggregate if missing): closed-form A at each t0 on a 0.01 ns bracket search around the mf seed, window = samples with t − t0 in [−20, 160] ns. The two-τ enters only as the first alignment reference; iterations 1–2 use the sampled template.
3. **Points.** (τ_i, y_i/A) for every sample in the window, with σ_i = rms/A.
4. **Bins.** 0.5 ns bins on [−20, 160] ns (8 phases per sample); per bin the median, uncertainty 1.4826·MAD/√n (σ_pulse/A for n = 1), n; no bin is dropped (the weights carry the statistics). With 50–200 pulses and uniform trigger phase each bin holds 6–25 points.
5. **Spline.** Weighted least-squares cubic B-spline (`scipy.interpolate.make_lsq_spline`) through the bin medians with weights 1/σ_bin; interior knots every 0.5 ns on [−1, 10] when the pool has ≥ 100 pulses, else every 1 ns; 1 ns on (10, 20], 2 ns on (20, 40], 4 ns on (40, 80], 8 ns on (80, 160] (peak at ≈ 6 ns after onset for τ_r ≈ 2.5, τ_f ≈ 24); if `make_lsq_spline` rejects the knots (Schoenberg–Whitney), double every knot spacing and retry, recording the final plan per module; a pseudo-point (160 ns, 0) with weight 10× the median weight pins the end to zero. Post-processing: onset `t_on` = the last time before the peak at which the spline ≤ 0.5 % of its maximum; the template is 0 for t < t_on, the time axis is shifted so `t_on` = 0 (shift recorded as `onset_shift_ns`), and the curve is divided by its fine-grid maximum (unit peak). Per-bin uncertainties are kept on the shifted axis.
6. **Iterations 1 and 2.** Refit (A, t0) per pulse against the current sampled template (same bracket search, the template through the 0.05 ns table); per-pulse χ²/dof with σ = rms (no model floor, so pulses that disagree with the template are the ones dropped); drop the worst 20 %; re-pool, re-bin, refit the spline (steps 3–5). After iteration 2: final template, the final per-pulse χ²/dof distribution, the residual pattern per bin, and N per iteration are stored.
7. **Amplitude bands.** Steps 2–6 repeated on `b_lo` [100, 400] and `b_hi` [400, 2500] when each holds ≥ 20 pulses → `shape_lo`, `shape_hi`, with max |Δ| on [0, 20] ns and the I_int ratio.
8. **Run-type average.** The same procedure on a pool of ≤ 20 pulses from every module with `fallback = 0` → `shape_avg`, stored and used for `fallback = 2`.
9. **Derived quantities per module.** `t_pk`, `t50` (50 % crossing on the rise), `iint_wa` (walk-out integral per unit amplitude, phase-averaged over 256 phases, on the triangle-smoothed shape, the same code as the bank), `area`, `chi2_ndf` (median final), `n_iter[3]`, `band`, `fallback`.
